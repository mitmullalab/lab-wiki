# lab-wiki

Home for technical documentation used by the [Bike Shop][homepage]'s
(led at MIT by [Sendhil Mullainathan][sendhil]).
Documents here should be high-signal, containing verified and cited information,
and be useful for human and AI consumption.

Documents:

- [Lab Wiki (external Google Doc)][lab-wiki-doc]: general-purpose wiki organized into tabs.
  This document covers both technical and non-technical lab topics,
  including onboarding, expense tracking, and lab administration.
- [`COMPUTE.md`](COMPUTE.md): documents various sources of compute,
  designed to be referenced by autoresearch AI systems when acquiring and using compute.
